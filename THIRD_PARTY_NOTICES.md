## Runtime dependencies

- Audiveris 5.11.0: GNU AGPL v3. Vendored Java patches retain upstream notices
  and the license in `livesheet/vendor/audiveris/`.
- PyMuPDF 1.26.7: used under its AGPL option.
- MuseScore Studio 4.7.4: GPL-licensed renderer/exporter. The bootstrap script
  downloads the official release package. Its upstream notices stay in the image.
- Tesseract English trained data: official `tessdata` 4.1.0 release, Apache-2.0.
- Eclipse ECJ 3.44.0: upstream Eclipse compiler, with its license metadata inside
  the pinned JAR. Used to build the Audiveris compatibility patches.
- Pillow, mido, packaging, Python, OpenJDK and Ubuntu system packages retain
  their respective upstream licenses and notices.

Exact asset URLs and SHA-256 digests are in `tools/bootstrap.py` and Dockerfile.
The image contains installed dependency metadata. This list is not a replacement
for each dependency's full license. Review distribution/source-offer requirements
before publishing an image or offering a hosted service.

## Test data

`tests/corpus/` contains scores authored for this project's synthetic benchmark.
The source MusicXML and expected results are included under the repository
license. PDF, MusicXML and MIDI exports were generated by MuseScore. Font variants
are Leland, Bravura and Petaluma. The generated references are development tests,
not an unseen accuracy benchmark.

`tests/fixtures/native/` contains companion data derived from the Mutopia Project's
public-domain editions. `index.json` preserves source links, editor attribution
and license links for Mutopia 74, 61 and 468. `chopin-web.json` is the earlier web
representation of Mutopia 468 used to check conversion compatibility.

Private uploaded PDFs and their derived regression excerpts are intentionally
excluded from Git and container builds. They may be supplied locally for review.
